# 情绪周期分析

## 执行流程

### 1. 采集数据

运行数据采集脚本获取市场宽度、板块、新闻、市场状态和温度（默认 A 股）：

```bash
python3 scripts/gather.py [A|HK|US]
```

### 2. 情绪指标

- 市场温度和策略姿态
- 上涨/下跌家数与涨跌停比
- 成交额及放量/缩量状态
- 板块扩散度和领涨持续性

### 3. 情绪周期阶段

| 阶段 | 特征 | 操作 |
|------|------|------|
| 冰点期 | 下跌家数和跌停数扩大，温度处于低位 | 等待宽度企稳 |
| 回暖期 | 宽度改善，涨停增加，主线开始扩散 | 小仓试错 |
| 狂热期 | 高温、全面普涨、补涨扩散且成交额显著放大 | 降低追高意愿 |
| 退潮期 | 高位放量阴线、分歧加大、龙头开板 | 清仓观望 |
| 恐慌期 | 放量暴跌、跌停潮、恐慌性抛售 | 等待企稳 |

### 4. 逆向信号

转折必须由至少两类独立市场数据共同确认（如宽度 + 成交额）。只有单日涨跌或数据缺失时，输出“未确认”并列出缺失证据。

## 输出要求

1. 当前情绪周期所处阶段
2. 关键情绪指标数值
3. 情绪拐点信号是否出现
4. 基于情绪周期的操作建议
5. 需要警惕的风险因素
