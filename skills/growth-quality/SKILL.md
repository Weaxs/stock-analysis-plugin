# 成长质量分析

## 无状态分析扩展

财报前后期变化或同行验证时，MUST 读取[无状态研究工具](../stock-analysis/references/stateless-analysis.md)中的同行和公告财报比较，使用 compare_stocks/analyze_disclosure_changes 整理同口径指标与正文证据，再解释经济含义。

## 输入数据说明

先运行：

```bash
python3 scripts/gather.py <symbol>
```

gather 工具返回：
- `quote` — 实时行情（PE/PB/市值）
- `kline` — 60 日 K 线数据
- `technical` — 技术指标（趋势确认）
- `financials` — 财务数据（核心数据源）
- `news` — 近期新闻（业绩/行业信息）
- `stock_info` — 公司基本信息（行业、板块）
- `sector_rankings` — 板块排名

需要财务趋势时调用 `get_financials(symbol, annual=true, periods=10)`。港股配置 `LIXINGER_TOKEN` 后优先理杏仁非金融公司财报，按真实 `report_type` 判断年报，保留实际财年末、披露日期、币种；历史 ROE/毛利率/净利率为百分数，顶层 `roe/profit_margin` 延续小数比例。读取 `available_periods/warnings`，缺期不补造。有效 Yahoo 顶层快照与历史行分开读：`currency` 为快照财报币种、`market_cap_currency` 为市值币种，历史币种在 `periods` 每行，`snapshot_source` 标记快照来源；null 不用历史值补成跨期或跨币种数字；顶层 `report_date` 未知时读取 `periods` 的历史日期，不当作当前快照报告期。

`financials` 通常只是单期摘要。多期趋势、经营现金流、应收账款或同业估值未返回时，把对应维度标为“数据不足”，不推断趋势、不计分。

## 分析框架（4 步法）

### 1. 成长性评估

核心财务指标分析：
- **营收增速**：同比增长率、环比变化趋势
- **净利润增速**：与营收增速的匹配度
- **经营现金流**：是否与利润同步增长
- **ROE 水平**：绝对值 + 变化趋势

### 2. 质量评估

判断成长是否可持续：
- **ROE 稳定性**：连续多期保持高水平 vs 大幅波动
- **现金流匹配**：经营现金流/净利润 > 0.8 为优质
- **毛利率趋势**：稳中有升 = 竞争优势增强
- **应收账款**：大幅增加可能意味着放宽信用条件换取增长

### 3. 估值容忍度

成长是否已被估值透支：
- PE 与增速匹配度（PEG 分析）
- PB 是否过度反映未来成长
- 市值/营收比是否合理
- 同行业估值对比

### 4. 趋势确认

基本面正面但技术未确认时需观察：
- 上升趋势 + 基本面改善 = 加分
- 下降趋势 + 基本面改善 = 可能是价值陷阱，需等待拐点
- 放量突破 = 市场认同成长逻辑

## 评分调整规则

基准分 50，根据以下条件调整：
- 营收+利润+现金流+ROE 全面改善：+15
- 行业高景气 + 公司份额提升（共振）：+6
- PEG < 1 且增速 > 20%：+6
- 高估值（PE > 50）但增速尚未验证：-8
- 增收不增利（毛利率下滑）：-12
- 现金流与利润严重背离：-10
- ROE 持续下滑：-8

## 输出格式

1. 成长画像（一句话概括公司成长阶段）
2. 核心财务指标分析表
3. 成长质量评级（优质/一般/存疑）
4. 综合评分（0-100）及理由
5. 投资建议与关注风险点

只有收入、利润、现金流和 ROE 均有可比多期数据时，才可给出“优质”结论；否则完成标准是给出已验证项、缺失项和最小补证建议。

用户要求长期质量、五到十年财报或 ROE/利润率趋势时，补充 `get_financials(symbol, periods=10, annual=true)`；逐年比较同口径年报，实际可得年份不足时明确标注，不以最近十个季度代替十年。结合 `get_valuation_history` 检查估值分位，分位窗口以实际返回数据为准。

### 补充数据覆盖

指数估值可用 get_index_valuation；中证补充多年滚动 PE，配置 LIXINGER_TOKEN 可补理杏仁 mcw 历史 PB。每个指标按其来源/口径使用，不把缺失 PB 或近期 PE1 当长期数据。
