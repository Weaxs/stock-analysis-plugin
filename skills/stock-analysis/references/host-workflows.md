# 宿主研究与报告交付

在批量筛选、多角色研究、网页证据补充或报告文件交付时使用本文。先读取当前宿主实际提供的工具说明；没有相应能力时按原有股票工具流程完成任务。

## 批量研究与 PTC / codemode

1. 独立股票或维度可并行取数；沿用已有 gather / 批量工具，不对同一数据重复请求。
2. dsh 的可选研究配置启用 PTC `persistent-in-memory`。按当前宿主生成的 SDK 调用股票工具；本插件输出为 JSON 文本，需要解析后再计算。Pi codemode 同样先查看工具声明，按实际返回类型解析。
3. 在会话内保留本次采集结果、派生数组及函数，进行筛选、同行比较与参数敏感性分析；每项结果携带标的、币种、复权口径、覆盖期间、来源和实际数据日期。先排除 error、缺失与口径不一致的数据，再计算；未知值不补零。
4. 新的实时行情问题重新取数；复用的数据必须标为其原始时点的快照。内存不等于最新行情，也不作为持仓或账户存储。
5. dsh persistent 模式使用最终表达式或 console.log 返回结果，没有顶层 return；复用已有变量时赋值或换新变量名，避免重复 let/const 声明。超时、取消、重启或恢复会话后重新建立状态。
6. Pi codemode 使用它自己的脚本规则，不套用 dsh REPL 语法。工具声明中已有的 integer、上下限、枚举与默认值都必须遵守；模型缓存是否保留由宿主和所选 provider 决定。

## 分工研究

仅在问题确实涉及多个独立维度且当前宿主提供委派工具时分工。简单报价或单工具查询直接回答。

dsh 可选研究配置提供 `stock_research_subagent` 和三个 `agent_preset`：

| 预设 | 任务 | 交回父任务的内容 |
| --- | --- | --- |
| stock-fundamentals | 基本面、财务质量与估值 | 字段、报告期、币种、口径、来源与缺失 |
| stock-technical | 技术结构、策略回测与验证 | 数据覆盖、复权、参数、费用、结果与限制 |
| stock-events | 公告、事件与原文核对 | 原文 URL、事件/披露时间、事实与未验证点 |

向每个子任务明确传递股票、市场、研究时点、问题、已有证据与需要返回的字段；spawn 不自动继承父任务全部背景。子任务仅返回研究证据，父任务核对冲突、重复与市场适用性后形成结论，不能把三个子任务的意见投票变成买卖信号。

如宿主可实时查看、steer 或 stop 子任务，发现跑题时及时纠正并使用其已验证的部分结果。dsh 角色使用宿主原生工具可见性限制；这不是不可信插件的安全沙箱。

## 网页证据

dsh 开启 DeepSeek Search/Fetch 后，通过当前提供的网页搜索工具检索，再读取原文。记录 URL、发布/事件日期和适用市场；搜索摘要只作线索。行情、财务与回测数值仍以结构化股票工具的实际返回为准。

Search/Fetch 未配置、失败或权限不足时，使用现有可用检索工具；不能将失败写成“没有相关新闻”。缺少原文或时间时在结论中标明证据缺口。

## 最终报告与文件交付

1. 完成证据核对、用户要求的归档/信号记录及其他操作后，再渲染最终报告。
2. 两个报告工具的 `final` 默认 false。只有本轮只剩将报告回复给用户时才传 `final=true`；支持原样交付的 OpenClaw 可立即结束本轮。错误结果继续交给模型处理；旧宿主仍返回原 JSON，按 content 展示 Markdown。
3. 用户需要文件、邮件或 Drive 等交付时，保持 `final=false`，从成功结果取 `format=markdown` 的 `content`，用宿主现有文件工具保存为工作区中的 `.md` 文件。文件名使用明确标的/市场与报告日期，已有文件先确认可覆盖或使用新名称。不能把 Markdown 改后缀冒充 PDF。
4. Hermes 连接器的文件输入使用实际本地绝对路径；读取当前连接器 schema，单文件传路径，多文件按其数组格式传入，不编造上传描述对象。返回文件使用宿主给出的 path，失败文件保留其错误。
5. 按用户已经授权的目标及内容发送。只有连接器返回成功才报告已交付；尚无目标或权限时保留本地文件并说明待完成项。连接器不支持当前执行后端的路径时，提供本地报告，不虚构链接。
6. 用户指定只保存或尚需审核时，完成本地文件即可。完整分析内容与来源留在报告中，交付后的回复只给实际文件或成功回执。

宿主配置见各接入指南：dsh 研究与搜索 overlay 为可选配置；Hermes 可在研究 profile 用 `skills.auto_load: [stock-analysis:stock-analysis]` 常驻综合方法，其他策略 skill 按任务加载。
