# 趋势追踪分析

## 核心理念

趋势追踪用可执行的规则参与趋势，通过控制试错损失、保留盈利空间捕获少数大行情。肥尾描述收益分布，趋势描述价格路径；肥尾指标不是趋势启动或延续信号。

用户询问塔勒布、肥尾计算、极端行情或策略是否依赖少数大盈利时，先读取 [肥尾度量与趋势收益诊断](references/fat-tails.md)。概念问题直接解释方法；需要具体统计结果时，按参考中的数据口径准备输入并调用 `scripts/tail_analysis.py`。普通趋势判断无需加载这份参考。

仅解释肥尾概念时，到此完成；下述流程用于具体标的的趋势分析。

用户要求运行股票池月度右侧趋势策略时，MUST 先读取 [月度右侧趋势策略](references/monthly-trend-strategy.md)，将股票名称解析为代码、按市场分组，直接调用 `analyze_trend_strategy(symbols, ...)` 自动取行情；仅在用户提供时传入真实持股集合，报告动作、原因与新仓预算。MUST 保留 `not_validated` 及跨样本失败边界；用户明确采用的规则可输出条件计划，实际成交和个人持仓由调用方核实。

仅要求解释多期限方向或复核旧温度时，先读取 [多期限月度趋势](references/trend-horizons.md)，调用 `get_technical_analysis` 的 daily、count=360，优先解释 `trend_horizons` 的21/63/252期限组成、方向与观察日期。当前仍为 `not_validated`，MUST 说明交易有效性未被完整验证，MUST NOT 自行转换成交易建议。七档温度或旧模型复核才读取 [独立趋势温度](references/trend-temperature.md)并解释兼容字段 `trend_temperature`；仅用户明确要求七档时展示研究标签，不能把“平”当作零方向。这些都不是趋势动物、肥尾 κ、原综合评分或市场复盘温度；用户自定条件的研究回测仍可运行。

## 执行流程

### 1. 采集数据

运行数据采集脚本获取 120 根日K线及技术指标（相对本 skill 目录执行）：

```bash
python3 scripts/gather.py <symbol>
```

确认数据日期、周期和复权口径；120 根日K线用于近期趋势判断。肥尾分支按参考文件另取历史收益，报告实际取得的区间和样本量。

多期限分支报告 `model/validation_status/components/positive_count/negative_count/neutral_count/direction/decision_as_of/as_of/price_basis`；不足月初预热时先解释不可用，不能改用零值。通用采集脚本仍默认120根，不能据它声称已完成252根趋势判断，需另取daily、count=360。旧温度分支报告模型、EMA差方向、分数、日期及口径；七档只按明确请求补充。先确认观察K线收盘，未知价格口径需说明；不把样本不足当中性趋势。

### 2. 趋势确认

**多头趋势确认条件**：
- 均线多头排列：MA5 > MA10 > MA20 > MA60
- MACD 在零轴之上运行
- 价格沿着上升通道运行
- 每次回调不破前低

**空头趋势确认条件**：
- 均线空头排列：MA5 < MA10 < MA20 < MA60
- MACD 在零轴之下运行
- 价格沿下降通道运行

报告哪些条件已满足、哪些尚未满足，并给出对应数值或价格位置。空头趋势对仅能做多的股票账户意味着退出或观望；做空建议须有对应市场和账户能力。

### 3. 趋势阶段判断

| 阶段 | 特征 | 操作 |
|------|------|------|
| 启动期 | 均线粘合后向上发散，放量突破 | 检查入场触发和初始风险 |
| 加速期 | 价格加速上涨，远离均线 | 按持仓规则跟踪，更新保护位 |
| 成熟期 | 涨幅放缓，量能递减 | 检查退出条件，阶段标签本身不触发减仓 |
| 衰退期 | 跌破预先选定的均线或趋势支撑 | 按退出规则执行 |

### 4. 关键指标

- **ADX 替代**：用 MA 斜率和排列程度衡量趋势强度
- **趋势线**：连接近期低点作为上升趋势线
- **回调幅度**：描述相对前一波涨幅的回撤及是否破坏支撑；斐波那契比例只作为观察位置，不能单独证明回调健康。

### 5. 形成交易规则

先读取 [短线交易决策框架](../stock-analysis/references/short-term-trading.md)的风险单位和市场成交约束，再形成同一套入场、持仓和退出规则：

- **入场**：指定周期、触发条件、判断时点和成交假设。例如收盘突破此前 20 根K线最高价，阈值排除当前K线；历史检验使用信号产生后可成交的价格。
- **初始风险**：给出初始止损、单笔风险预算和仓位。按预算 / 入场到止损的每股损失估算数量，并受资金、交易单位和组合风险限制；跳空和无法成交可能使实际亏损超过预算。
- **持仓**：趋势条件持续满足时保留盈利空间。保护位随有利走势更新，做多止损只上移；涨幅大或收益处于高分位本身不构成退出条件。
- **退出**：明确采用均线失效、通道破位或移动止损中的哪一种、如何触发。固定止盈属于可选策略约束，要说明它可能截断大盈利；参数是待检验假设，不归为塔勒布公式。

规则完成标准：每项都有可核验的触发条件，说明下一次观察时点，以及触发后动作。用户已有规则时按其规则评价，调整另列为建议。

### 6. 按需检验

用户要求历史验证时使用 [策略回测](../strategy-backtest/SKILL.md)。先核对现有 DSL 能否表达规则，无法表达的条件标为未验证；不以近似规则冒充原策略。趋势收益的利润集中度诊断按肥尾参考文件执行。

## 输出要求

分析完成后输出：
1. 当前趋势方向和阶段
2. 趋势证据和未满足条件
3. 关键趋势支撑/压力位
4. 入场/持有/离场建议
5. 初始风险、保护位和退出触发条件
6. 数据或成交限制；肥尾分支附计算口径和不确定性

### 市场环境入场实验

用户要求验证宽基右侧条件如何约束趋势入场时，读取[多期限参考中的市场环境实验](references/trend-horizons.md#市场环境入场实验)，准备带足预热的个股/同市场宽基daily OHLCV JSON，再运行 `scripts/market_trend.py`。该脚本调用共享Python核心，输出真实规则的三期限研究结果。MUST 分清初始空仓与已有持仓、观察与成交、开发集与新标的复核；不得拿七档标签代替入场条件，或将通过单次历史门槛称为稳定有效。
