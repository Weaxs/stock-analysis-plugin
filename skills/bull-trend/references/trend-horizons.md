# 多期限趋势

通过现有get_technical_analysis请求daily、count=360，读取trend_horizons。模型用21/63/252根日K约代表1/3/12个月，不强凑七档标签，不是星球公式或肥尾预测。

## 计算与解释

每期限过去对数收益为 log(close_t)-log(close_(t-h))。每个月第一根可见、正成交量日K的收盘形成观察，其后保持到下个月首根有效日K收盘。未提供volume时只能沿输入记录观察；提供volume时零成交量记录不计回溯根数。观察K线必须已收盘，任何研究成交使用之后的开盘。

components逐一返回period与log_return，positive_count/negative_count/neutral_count统计三期限方向；至少2个为正/负则direction为up/down，全部零为flat，其他为mixed。它们是已发生路径的描述，MUST NOT 解释为独立投票概率、未来涨跌概率或自动配置比例。相关期限不能当作独立样本。

仅支持daily输入。最长需在月度观察时已有253根有效收盘；最新已有253根而当月首根尚不足时仍不可用，不能用最新日重新计算冒充月度观察。建议请求360根，报告实际history_start、as_of、decision_as_of及price_basis。数据不足、混用调整标记或坏日期必须报告unavailable_reason，不伪造中性。多周期摘要保留整个trend_horizons，周/月K返回requires_daily_bars。

当前validation_status=not_validated。旧trend_temperature为兼容的EMA/ATR研究描述；不再将它的七档视为默认趋势模型。新字段也不能覆盖原综合评分或买卖信号。

## 回测与证据边界

DSL指标monthly_momentum复用相同Python计算，period默认63。它是单期限信号。三期限研究组合从相同起点分别给初始资金三分之一，独立留存盈亏、权重漂移，并没有每月等权再平衡；并行买卖分别计费，没有跨子账户净额撮合。研究另外拟合了一个跨市场共用的初始活跃资金比例0.8704，剩余现金不动；这是2022–2025研究集风险拟合结果，MUST NOT 作为用户账户默认仓位。

新12股复核：A/HK路径回报较旧规则提高，美股回报接近、回撤较小；但港股最大回撤恶化约6.1个百分点，未通过预设5个百分点门槛。因此没有建立跨市场统一优势，MUST NOT 称为已验证策略。A股研究用了供应商AdjClose因子OHLC，不等于完整投资者总回报；产品A股输入通常仍为qfq，不能直接照搬该收益。

原核心固定止损/止盈默认值不变；省略配置不代表禁用。单份普通YAML回测不会自动复制三子策略和预热协议。

研究背景：[Hurst/Ooi/Pedersen原文](https://www.aqr.com/-/media/AQR/Documents/Insights/Journal-Article/AQR-JPM-Fall-2017.pdf)讨论1/3/12个月趋势组合。本实现的个股多头、月初观察、正成交量过滤、资金漂移和风险拟合均为本项目假设，不是论文复现或七档背书。

## 市场环境入场实验

需复现“市场只限制新开仓”的研究时，使用同一skill的 `scripts/market_trend.py`，无需新增宿主工具或个人持仓数据库。输入是两份已取得的daily OHLCV JSON数组（个股、同市场宽基），包含date/open/high/low/close/volume；调整口径须在各自序列内一致。market-symbol标识调用者提供的市场输入，不自动下载或验证标的归属。研究代理固定A510300、HK2800.HK、US SPY；自换代理属于另一项实验。

```bash
python3 scripts/market_trend.py stock-daily.json market-daily.json \
  --symbol AAPL --market-symbol SPY --start 2022-01-01 --end 2025-12-31 \
  --capital 10000000 --allocation 0.8704
```

两份输入必须含评估开始之前的预热历史：个股最长252根过去收益在观察时需253根有效收盘，市场SMA200需200根。预热只计算指标，不建立虚拟持仓或产生收益。起点前最后有效收盘，以已知月度个股方向和当日市场条件初始化空仓目标；之后只在月度观察给出新开仓许可，次日有效开盘执行。市场close>SMA200允许新的月度正动量子策略进入；弱市不强制退出已持仓，个股月度动量<0仍退出。待买订单遇到下月许可失效会取消，不能冒充已持仓豁免。

脚本默认allocation=1，0.8704只为显式复现前轮研究，不是账户建议。21/63/252初始各分三份、按分向下取整，余款留现金，利润各自保留而非每月等权重置。费用固定佣金/滑点各每边0.1%，税与现金利息0；输出明确参数、资金、评估开始/预热开始、交易、净值和指标。采用本地JSON输入，不保存个人仓位、不下单。普通 `run_backtest` 的单份YAML不会自动执行这个三子策略或抓市场预热；不要冒充二者完全相同。

当前方法尚未通过完整跨市场效果门槛，`validation_status=not_validated`。MUST NOT 将局部样本上涨或相对旧模型改善称为稳定的跨市场交易优势。

## 温度状态与切换事件

解读星球信号或设计入场协议时，MUST 区分当前状态和新发生的切换事件：“今天仍热”不等于“今天温转热”。当前月度方向策略按状态选股，不是官方事件策略。事件协议须明确可得时间、有效期限和重复事件加仓条件；无合格新事件时，卖出所得留在现金。预热不产生新事件或虚拟持仓。外部同名温度的计算公式未公开，不能将成员筛选条件或自述收益作为官方规则或验证结果。
