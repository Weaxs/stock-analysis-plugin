## 严格复现仍缺什么

- N、各层宽度、dropout比例、优化器、学习率、batch、epochs、初始化种子和增量更新次数。
- 自定义盈亏损失函数的公式、盈亏与监督标签的结合方式。
- ROC成本函数、估计窗口、单一标签类别时的处理、阈值与模型更新的确切先后。§2.2与§2.3的文字不足以确定同周信号是否使用更新后模型。
- MC抽样次数、具体dropout位置、点预测与抽样预测的组合方式，以及80%判断的精确边界。
- 表2的损失统计口径、起始资金、冷启动胜率/配权、剔除后的恢复条件；$300为金额阈值，不能静默换成某个百分比或其他币种数额。
- 周一/周五休市、无成交、复权价格、分红、尾盘成交价的处理与冻结数据。论文结果不含交易成本（第7页），不能声称已证明净收益。

本 skill 实现下述统计计算及独立配权分项对照，不以猜测填补神经网络缺项。计算与回测工具参数见 [计算与回测接口](computation.md)。完整模型需作者源码或补充材料。跨市场时区、汇率、费用和结算是额外工程扩展，MUST 与论文复现结果分开报告。

## 计算脚本

### 预测分布集中度

```bash
python3 {baseDir}/scripts/rotation_metrics.py confidence predictions.json
```

输入为同一ETF、同一决策时间、同一模型的MC-dropout输出数值数组，2..100000个。不能混合不同标的、模型或日期。输出样本数、中位数、总体标准差（ddof=0）、区间内经验占比及判断。数值输出可正可负，线性输出不要求在0..1。

脚本采用包含区间边界、占比 `>=0.8` 的明确计算约定，原文未精确规定等号边界，因此标记为部分计算而非严格完整复现。总体标准差为0时占比仍可计算，但判断为null：重复输出无法证实MC dropout确实开启。此保护不冒充作者的原始实现。

集中度高的预测可以全部为负；它不验证方向正确、模型校准或盈利能力。输入来源、模型与决策时间由调用方随报告记录，脚本无法从裸数组验证这些事实。

### 历史原始配权

```bash
python3 {baseDir}/scripts/rotation_metrics.py allocation counts.json
```

输入为1..100条记录，例如：

```json
[{"symbol":"510300","buys":4,"wins":3,"streak":2},
 {"symbol":"1306.T","buys":2,"wins":0,"streak":0}]
```

对应原始分数为2.25和1.0。symbol只是唯一标识，无市场限制；同一标的的不同代码别名必须先统一。计数为非负整数且 `streak <= wins <= buys`，只包含决策前已完成的交易；持平不算盈利。各计数的年度重置口径仍需作者材料确认。

`buys=0` 时 `raw_weight=null`，原因是原文未定义除零及冷启动处理。脚本不补默认分数，不把分数归一化为组合预算，也不根据这些分数筛选ETF。输入文件最大8 MiB，未知字段、重复JSON键、重复标识及非法数值均拒绝。
